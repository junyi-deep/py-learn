# 第一阶段：Python 基础

1. 让 Python 开口：语法、注释、变量、输入输出
2. 数字与文本加工厂：数字、运算、转换、字符串
3. 程序的岔路口：比较、布尔值、条件控制
4. 数据收纳盒：列表、元组、字典、集合
5. 重复任务流水线：for、while、break、continue
6. 把代码装进工具箱：函数、参数、return、作用域
7. Python 的快捷通道：推导式、zip、常用数据结构
8. 可靠计算的积木：datetime、math、random、statistics
9. 一件一件送上流水线：迭代器、生成器、yield
10. 给代码加上自动开关：with、上下文管理器、装饰器
11. 把程序拆成可读零件：模块、`__name__`、类型注解
12. 为意外准备安全网：错误与异常
13. 让数据和行为住在一起：面向对象
14. 在文件系统中安全行走：File、pathlib、OS、StringIO
15. 先查工具箱，再造轮子：内置函数与标准库概览
16. 给文本装一台模式雷达：正则表达式
17. 让数据跨程序旅行：JSON、XML、CSV、Pickle、Markdown
18. 观察并调度外部程序：sys、subprocess、logging
19. 让多个任务协调前进：threading、queue、asyncio
20. 把请求送到另一台机器：socket、urllib、requests
21. 理解早期 Web 通信：SMTP 与 CGI 历史知识
22. 和结构化数据仓库对话：MySQL 与 MongoDB 客户端
23. 从网页中提取有用信息：爬虫、Scrapy、Selenium
24. 把结果变成看得见的界面：PyQt、pyecharts
25. 把模型能力接进程序：OpenAI 风格 API 与 AI 绘画
26. 用数据衡量收益与风险：Python 量化入门
